# ⛅ Weather Forecast App

A dynamic, three-page responsive weather application that provides real-time forecasts. This project leverages live API mapping and features immersive dynamic video backgrounds that change based on current weather conditions.

## 🚀 Live Demo
👉 **[Click Here to View Live Demo](https://weather-app-lxrj.onrender.com/)**

## ✨ Key Features
* **Real-Time Weather Data:** Fetches accurate, up-to-date weather information and forecasts using the OpenWeatherMap API.
* **Dynamic Video Backgrounds:** The application automatically updates its video backgrounds to match the current local weather conditions, providing a highly immersive user experience.
* **Live API Mapping:** Interactive location-based weather tracking seamlessly integrated across three distinct pages.
* **Responsive Design:** Fully optimized layout for perfect viewing on desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
* **Frontend:** React.js
* **API:** OpenWeatherMap API
* **Deployment:** Render

## 💻 Getting Started

### Prerequisites
* Node.js & npm 
* An API key from [OpenWeatherMap](https://openweathermap.org/)

### Frontend Setup
1.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Configure Environment Variables:**
    ```bash
    REACT_APP_WEATHER_API_KEY=your_api_key_here
    ```
4.  **Start the development server:**
    ```bash
    npm start
    ```
